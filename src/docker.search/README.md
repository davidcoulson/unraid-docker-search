**Docker Search**

Adds a search box and quick filters to the top of the Docker containers list: type to filter by name, image, folder, network, IP or port (`image:linuxserver`, `is:unhealthy`, `-is:running`), or click a chip for running, stopped, healthy, unhealthy, update available, autostart, WebUI or CPU pinned. Works with folder.view2 folders. Press `/` to search, `Esc` to clear.
